# Удалённые подключения (SSH) — заметки о будущем

> Статус: **не реализовано и не в работе.** В Orbito нет SSH-клиента, удалённого выполнения команд и экранов авторизации. В интерфейсе пункт «SSH» отмечен как «Coming Later» и неактивен. Документ фиксирует, где проходят границы, чтобы удалённое управление Mac'ами можно было добавить позже без переписывания приложения.

## Текущие точки расширения

| Слой | Сейчас | Что понадобится для SSH |
|---|---|---|
| Выполнение команд | `CommandRunning` (`ProcessCommandRunner`, `RecordingCommandRunner`) | `SSHCommandRunner`: те же `executable` + `arguments`, передаваемые с экранированием на удалённую сторону; тайм-аут; отмена |
| Файлы | `PlistService` / `JobOperations` работают через `FileManager` | Вынести чтение, атомарную запись и исключающее создание файлов в протокол (`ConfigurationStore`); удалённая реализация через SFTP |
| Идентичность задания | `LaunchJob.id` = путь к plist | Составной ключ `connectionID + label`, чтобы одинаковые Label на разных машинах не конфликтовали |
| История | `CommandRecord.connection = "Этот Mac"` | Имя подключения уже хранится в каждой записи |
| Интерфейс | раздел «Подключения» показывает только «Этот Mac» | Список подключений, состояние связи, повторное подключение |

Абстракции специально не вводились заранее. Протоколы появятся тогда, когда появится вторая реализация.

## Требования к будущей реализации

- **Модель подключения:** имя, хост, порт, пользователь, способ входа (ssh-agent, ключ, пароль), платформа. Секреты никогда не хранятся в `Codable`-полях. В Keychain хранится только ссылка на элемент.
- **Проверка host key** обязательна: известные хосты, явное подтверждение отпечатка при первом подключении. Никакого `StrictHostKeyChecking=no`.
- **ssh-agent** — способ входа по умолчанию. Файлы ключей указываются только путём; их содержимое Orbito не читает.
- **Надёжность:** тайм-ауты подключения и команд, обработка обрыва связи посреди операции. Если состояние после обрыва неизвестно, это прямо сообщается пользователю (как и при локальном тайм-ауте).
- **Права:** только задания пользователя, под которым выполнен вход. sudo — никогда автоматически.
- **Резервные копии** создаются на удалённой машине рядом с конфигурацией и дублируются локально.
- **Безопасное выполнение:** argv экранируется для удалённого shell одной функцией с тестами. Никакой конкатенации пользовательских строк.
- **Удалённые логи:** чтение хвоста файла частями, без загрузки файла целиком.

## Вне рамок

Управление Linux-планировщиками (systemd, cron) — в том числе удалённое — **не планируется**. Linux в Orbito существует только как справочник CLI-команд в Developer Mode.
